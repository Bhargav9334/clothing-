## 📖 Overview

A responsive fashion e-commerce front end built with React and Tailwind CSS. Shoppers can browse products, view product details, save items to a wishlist, manage their cart and go through checkout, with login and signup handled through modal dialogs and shared auth context.

## ✨ Features

- **Product catalogue** — product listing and detailed product pages
- **Shopping cart** — add, update and remove items
- **Wishlist** — save favourite products for later
- **Checkout flow** — complete order journey
- **Authentication** — login and signup modals with React Context
- **Refer & earn**, about and contact pages
- Scroll-to-top helpers, smooth animations and a fully responsive layout

## 🛠️ Tech Stack

| Layer | Technologies |
|---|---|
| Frontend | React, Vite, React Router, Context API |
| Styling | Tailwind CSS, Headless UI, Radix UI, Framer Motion |
| Utilities | Axios, Lucide & React Icons |
| Deployment | Vercel |
